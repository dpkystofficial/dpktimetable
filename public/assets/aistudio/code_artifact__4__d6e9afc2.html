ใช้ LINE Official Account (Messaging API) ร่วมกับ Google Apps Script เพื่อส่งแจ้งเตือนเข้ากลุ่มครูและนักเรียน

ขั้นตอนที่ 1: สร้างบอทแจ้งเตือนใน LINE Developers Console
  1. เข้าไปที่เว็บไซต์ https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE ของโรงเรียนหรือแอดมิน
  2. สร้าง Provider (เช่น ชื่อโรงเรียนดอนแก้วปากเป่งคุยสำโรง) และเลือกสร้าง Channel แบบ "Messaging API"
  3. ไปที่แท็บ Messaging API ของ Channel ที่สร้างขึ้น เลื่อนลงมาที่หัวข้อ Channel access token (long-lived) แล้วกดปุ่ม Issue จากนั้นคัดลอกรหัส Token มาวางในช่อง LINE Channel Access Token บนเว็บนี้
  4. ในแท็บเดียวกัน ให้เปิดสวิตช์ Allow bot to join group chats เพื่อให้สามารถเชิญบอทเข้ากลุ่ม LINE ของครูและกลุ่ม LINE นักเรียน ป.1 - ม.3 ได้
ขั้นตอนที่ 2: สร้างตัวกลางส่งข้อความด้วย Google Apps Script (แก้ปัญหา CORS และดูรหัสกลุ่มอัตโนมัติ)
  1. ไปที่ https://script.google.com กดปุ่ม โครงการใหม่ (New Project)
  2. ลบโค้ดเดิมออกทั้งหมด แล้ววางโค้ดด้านล่างนี้ลงไป:
  1. กดปุ่ม การทำให้ใช้งานได้ (Deploy) มุมขวาบน → เลือก การทำให้ใช้งานได้รายการใหม่ (New deployment)
  2. เลือกประเภทเป็น เว็บแอป (Web app), ช่อง ดำเนินการในฐานะ (Execute as) เลือก "ฉัน (Me)" และช่อง ผู้ที่มีสิทธิ์เข้าถึง (Who has access) เลือกเป็น "ทุกคน (Anyone)" จากนั้นกด Deploy
  3. คัดลอก URL ของเว็บแอป (Web App URL) ที่ลงท้ายด้วย /exec มาวางในช่อง Google Apps Script Web App URL บนหน้าตั้งค่า LINE ของเว็บนี้
ขั้นตอนที่ 3: วิธีดูรหัส Group ID ของกลุ่มครูและกลุ่มนักเรียนแต่ละชั้นอย่างง่ายดาย
  1. นำ Web App URL จากขั้นตอนที่ 2 ไปวางในช่อง Webhook URL ในหน้า LINE Developers (แท็บ Messaging API) แล้วเปิดสวิตช์ Use webhook
  2. แอดเพื่อนบอท แล้วเชิญบอทเข้ากลุ่ม LINE ครู หรือกลุ่ม LINE นักเรียนชั้น ป.1 - ม.3
  3. พิมพ์ข้อความว่า /id ในแชทส่วนตัวหรือในกลุ่ม LINE บอทจะตอบกลับพร้อมแจ้ง Group ID (ขึ้นต้นด้วย C...) หรือ User ID (ขึ้นต้นด้วย U...) ให้ทราบทันที!
  4. นำรหัส Group ID หรือ User ID ที่ได้มาใส่ในหน้าตั้งค่า LINE บนเว็บไซต์นี้ แล้วกดปุ่ม "ส่งข้อความตัวอย่างนี้เข้า LINE ทันที" เพื่อทดสอบได้เลยค่ะ

3. กำหนดสิทธิ์การเข้าถึงและแก้ไขข้อมูลรายเมนู (Granular Permissions) ติ๊กเลือกสิทธิ์ที่อนุญาตให้สมาชิกรายนี้ใช้งาน
